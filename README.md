# Zomato Power BI Dashboard

An interactive Power BI dashboard created to analyze and visualize Zomato restaurant data. The dashboard provides insights into restaurant performance, ratings, cuisines, locations, and other key metrics.

## Project Objective

The objective of this project is to transform raw Zomato data into an interactive dashboard that makes it easier to explore restaurant-related insights and identify patterns in the data.

The dashboard helps analyze:

* Restaurant performance
* Customer ratings
* Online delivery and table booking availability
* Popular cuisines
* Restaurant distribution across locations
* Cost and other important metrics

## Key Analysis

The dashboard provides insights into different aspects of the Zomato dataset, including:

### Restaurant Analysis

* Total number of restaurants
* Restaurant distribution across different locations
* Analysis of restaurant categories and services

### Rating Analysis

* Distribution of restaurant ratings
* Comparison of restaurants based on customer ratings
* Analysis of rating categories

### Cuisine Analysis

* Popular cuisines available across restaurants
* Distribution of restaurants by cuisine
* Comparison of different cuisine categories

### Location Analysis

* Restaurant distribution across different cities or locations
* Identification of areas with a higher number of restaurants

### Service Analysis

* Availability of online delivery
* Table booking availability
* Comparison of restaurants based on available services

## Tools Used

* **Microsoft Power BI** – Data analysis and dashboard development
* **CSV** – Dataset used for the analysis
* **Power Query** – Data cleaning and transformation
* **DAX** – Creating calculations and measures
* **Data Visualization** – Presenting insights through interactive charts and visuals

## How to View the Dashboard

1. Clone or download this repository.
2. Open the `ZOMATO DASHBOARD.pbix` file using Microsoft Power BI Desktop.
3. If required, reconnect the data source to `Zomato_dataset.csv`.
4. Explore the dashboard and interact with the available visuals and filters.
